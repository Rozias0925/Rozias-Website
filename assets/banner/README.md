# Banner photos

Put up to three public research, presentation, or academic-activity photos in this folder with these exact filenames:

- `banner-01.jpg`
- `banner-02.jpg`
- `banner-03.jpg`

Use horizontal 16:9 images whenever possible. Recommended export: 1920 × 1080 px (minimum 1600 × 900 px), JPG or WebP, ideally under 1.5 MB each.

The website uses `object-fit: contain` on a black stage. Every photo is shown in full; images with another aspect ratio receive black bars rather than being cropped.

If no banner photo is present, the original black geometric banner remains visible.
