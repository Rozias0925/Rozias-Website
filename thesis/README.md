# Simulation Benchmark

[Read the bilingual research report](https://rozias0925.github.io/Rozias-Website/thesis/)

Mixed-effects machine learning for small-sample longitudinal data, presented in two completed simulation studies:

- **Core study:** 15 settings and 3,350 simulation replicates, covering feature recovery, prediction, and function recovery.
- **Direction study:** 11 settings and 2,350 validation replicates, covering direction decisions and function recovery.

The report contains all 26 settings, model specifications, methods, and aggregate results in Traditional Chinese and English. This simulation study forms part of the author's project in collaboration with National Taiwan University Hospital. All simulation data are synthetic; no patient information was used in these simulations.

This repository serves the static report, local mathematical fonts, and the reviewed public data in `data/v1/`. `data/v1/manifest.json` records the provenance and SHA-256 hashes of the public data. `direction/example_curves_rep1.csv` contains curves from one prespecified illustrative simulation replicate.
